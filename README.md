# <sub><ruby>[*<sup>APL</sup>*](https://apl.wiki)<rt>The</rt></ruby></sub> [Sı̽gn <sub><ruby><sup><sub>the</sub></sup><rt>of</rt></ruby></sub> Tı̽mes](https://apl.news)<sup><sup><sub>[RSS FEED](https://apl.news/rss.xml)</sub></sup></sup>

To contribute, edit index.html then run `dyalog LOAD=path/to/apl.news` or on Windows, right-click folder and ("Show more options" and) "Run with Dyalog". Requires Dyalog v20.0+.

An editor will pop up. Fill in the fields and close the editor (you may be asked about replacing references; select Yes).

- `tags` can be space-separated (`'example idiom'`) or vector of vectors (`'example' 'idiom'`)
- `date` can be a vector (`2026 5 4`), single number (`20260504`) or text ('20260504' or '2026-05-04')

The system will ask for multiple articles. When done, simply close the editor while leaving at least one field empty.
